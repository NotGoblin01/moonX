# Machine Learning Models Directory

This directory will store trained ML models, feature encoders, vector embeddings, and similarity calculation pipelines (e.g., Scikit-Learn pipelines, cosine distance matrices, KNN models).

Future modules to add here:
- `similarity_scorer.py`: Feature normalization, weights adjustment, and similarity calculations.
- `trained_models/`: Serialized model artifacts (`.joblib` or `.pkl`).
